# Credix

Credix is a developer credibility and evidence verification platform.

## Project Structure

- `backend/` — Spring Boot backend
- `frontend/` — React frontend
- `docs/` — Project documentation
- `.github/` — GitHub configuration and workflows

## Tech Stack

### Backend
- Java 21
- Spring Boot 4.1.1
- Spring Web MVC
- Spring Security
- Spring Data JPA
- Hibernate
- MySQL
- Flyway

### Frontend
- React
- JavaScript
- Tailwind CSS

### AI
- Google Gemini

## Infrastructure

MySQL runs locally using Docker.

Docker is used only for the local MySQL database.
